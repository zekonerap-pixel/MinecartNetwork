# Sprite layout

- `mine_entrance.png`: 4 horizontal frames in order up, right, down, left; each frame is 24x28 source pixels.
- `minecart.png`: 4 horizontal frames in order up, right, down, left; each frame is 16x16 source pixels.
- `tracks.png`: vertical then horizontal; each frame is 16x16 source pixels.

All sprites render at 4x world scale. Procedural drawing remains fallback-only.
